Theory · for those who want to verify the logic

The formulas the filter runs on

Definitions, axioms and the theorem from the paper "Contextual Logic: An Axiomatic Framework for Neutralizing Self-Referential Paradoxes and Computational Hallucinations". The engine on this page implements them unchanged.

Definition 1 · state sets

A statement S belongs to exactly one of three global sets

T — true  ·  F — false  ·  U — undefined / neutral

Engine.sets() → { T, U, F }

Definition 2 · context operator

K ∈ ℤ is divided into three subtypes

K⁺ ∈ [1; +∞) ∩ ℤ;  K = K⁺ ⟹ S ∈ T
K⁻ ∈ (−∞; −1] ∩ ℤ;  K = K⁻ ⟹ S ∈ F
K₀ = 0;  K = K₀ ⟹ S ∈ U

CL.setOf(K) → K > 0 ? 'T' : K < 0 ? 'F' : 'U'

Definition 3 · mutual exclusivity

No element occupies two states at once

T ∩ F = ∅,  T ∩ U = ∅,  F ∩ U = ∅

One sign of K → one set. The registry stores one K value per fact.

Axiom 1 · context dependence

The status of S is not defined without context but is determined by the sign of K

K = K⁺ ⟹ S ∈ T
K = K⁻ ⟹ S ∈ F

A source evaluated without the K operator has no defined truth state.

Axiom 2 · asymptotics of objective knowledge

Knowledge that is objective in all contexts goes to infinity

K ⟶ ±∞

Objective truths are stable across the whole information space. In the interface, facts with |K| ≥ 10 are marked with the ∞ sign.

Axiom 3 · dynamic evolution of context

Each K is tied to time t and changes by a discrete delta ΔK

K(t₁) + ΔK = K(t₂)

Truth states are not permanent. The system updates knowledge when new context arrives.

Engine.evolve(id, ΔK, t₂)

Axiom 4 · grounding requirement

A nonzero K is admissible only if at least one consistent context exists

A statement S can be assigned a nonzero operator K only if there exists at least one consistent context in which the truth value of S does not contradict its own content. If there is no such context, that is, any assignment of K⁺ or K⁻ leads to a contradiction, S is assigned K = 0 by definition.

CL.tryAssign(S) enumerates T/F assignments for the reference graph of S and counts the consistent ones. None for K⁺ and K⁻ ⇒ K = 0.

Theorem · singularity ban

K = 0 if and only if S ∈ U

K = 0 ⟺ S ∈ U

Proof. By Definition 3 the sets T, F, U are strictly disjoint. By Axiom 1, S falls into T if and only if K = K⁺ ≥ 1, and into F if and only if K = K⁻ ≤ −1. When K = 0 the sign conditions are not met, and assignment to T or F is impossible. The only available storage is U. Hence K = 0 ⟹ S ∈ U. ◼

Corollary 1.1 · neutralizing the paradox

The liar paradox: "This statement is false"

Suppose S receives K⁺. By Axiom 1, S ∈ T, but the content of S asserts S ∈ F: a contradiction. Suppose S receives K⁻. By Axiom 1, S ∈ F, but then the statement S ("S is false") is true, that is, S ∈ T: again a contradiction. Neither assignment K⁺ nor K⁻ survives. By Axiom 4, S receives K = 0, and by the Theorem S ∈ U. This isolates the paradox and keeps it from causing a logical contradiction or an infinite loop in the engine.
